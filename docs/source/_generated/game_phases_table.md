| Phase | Definition | Tasks whose standard form names it |
|---|---|---|
| <a href="tasks/vocabulary.html#phase-acquisition">`acquisition`</a> | The phase in which a relation is first learned. | 2 |
| <a href="tasks/vocabulary.html#phase-extinction">`extinction`</a> | The learned relation is no longer in force: the cue comes without its outcome. | 1 |
| <a href="tasks/vocabulary.html#phase-transfer">`transfer`</a> | What was learned is tested on new material or under new conditions. | 1 |
| <a href="tasks/vocabulary.html#phase-devaluation">`devaluation`</a> | An outcome is made less valuable before responding is tested. | - |
| <a href="tasks/vocabulary.html#phase-test">`test`</a> | A later phase that measures what was learned, with no further learning intended. | - |
