# Dual N-Back Task

**HED task ID:** `hedtsk_dual_n_back`

**Family:** [Short-term and working memory tasks](families/working_memory_span.md)

**Also known as:** Dual N-Back

Two streams, a position and a spoken letter, run at once, and each item of each stream is compared to the one n items back.

## Description

Two streams run at once: a square moving among grid positions and a spoken letter on each trial. The participant responds separately when the position matches n back and when the letter matches n back. It is used mainly in working memory training studies.

## Inclusion test

An experiment is an instance of this task when its procedure matches, it manipulates at
least one of the listed variables, and it records at least one of the listed measures.

```{list-table}
:widths: 15 85
:header-rows: 0

* - **Procedure**
  - 1. On each trial a square appears at one of several grid positions and a letter is spoken.
    2. Participants respond separately when the position matches the one N trials back and when the letter matches the one N trials back.
* - **Manipulations**
  - Load level (N)
* - **Measurements**
  - - Hit rate for each stream
    - False alarm rate for each stream
```
