# Short-term and working memory tasks

A small set of items must be held, and sometimes manipulated, over a delay of seconds before a probe or reproduction; span, capacity or set-size effects are the measures.

This family contains 8 tasks.

## [Change Detection](../hedtsk_change_detection.md)

Brief sample array followed after a blank delay by a probe array; participant reports whether any item changed. Yields visual working memory capacity (K). Engages <span class="pop" tabindex="0">4 processes<span class="pop-card"><span><a href="../../processes/short_term_and_working_memory.html#hed-visual-working-memory">Visual working memory</a></span><span><a href="../../processes/short_term_and_working_memory.html#hed-active-maintenance">Active maintenance</a></span><span><a href="../../processes/selective_and_sustained_attention.html#hed-selective-attention">Selective attention</a></span><span><a href="../../processes/long_term_memory.html#hed-encoding">Encoding</a></span></span></span>. <span class="pop" tabindex="0">2 aliases<span class="pop-card"><span>Luck-Vogel Task</span><span>VWM Capacity Task</span></span></span>, <span class="pop" tabindex="0">3 variants<span class="pop-card"><span><a href="../hedtsk_change_detection.html#variants">Single-Probe Change Detection</a></span><span><a href="../hedtsk_change_detection.html#variants">Change Detection with Filtering</a></span><span><a href="../hedtsk_change_detection.html#variants">Continuous Report / Precision Task</a></span></span></span>.

## [Delayed Match-to-Sample](../hedtsk_delayed_match_to_sample.md)
