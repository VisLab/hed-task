# Artificial Grammar Learning Task

**HED task ID:** `hedtsk_artificial_grammar_learning`

**Family:** [Conditioning, reinforcement and implicit learning tasks](families/conditioning_and_reinforcement.md)

**Also known as:** AGL, Artificial Grammar, Artificial Grammar Learning

Exposure to letter strings generated by a finite-state grammar followed by a grammaticality judgment on novel strings; indexes implicit rule learning.

## Description

Participants are first exposed to letter strings (e.g., "MXRVXT," "VXTTRM") generated by a finite-state grammar, often under the cover story that they are memorizing the strings. In a subsequent test phase, they classify novel letter strings as grammatical or non-grammatical, performing above chance despite being unable to articulate the underlying rules. Reber (1967) introduced this paradigm as the first laboratory demonstration of implicit learning - the acquisition of complex, rule-governed knowledge without conscious awareness. The paradigm has been central to debates about the nature of implicit vs. explicit knowledge, the role of consciousness in learning, and the neural systems supporting rule abstraction.

## Game model

The standard form of the task, the one the inclusion test defines, as a game, in the terms
of the [game vocabulary](vocabulary.md). [The task model](../task_model.md) explains the
parts. A variant states only what it changes.

- **Game type:** <a href="vocabulary.html#game-study-then-test">Study, then be tested</a> (`study_then_test`)
- **Game rules:** every rule takes the default of the game type
- **Game motivators:**
  - *Why does the player try?* <a href="vocabulary.html#motivator-drive-instructions-only">instructions only</a>
- **Game phases:** none beyond the game's own structure
- **Game facets:**
  - Stimulus modality: <a href="vocabulary.html#facet-stimulus-modality-visual">visual</a>
  - Stimulus type: <a href="vocabulary.html#facet-stimulus-type-letters">letters</a>
  - Task I/O device: <a href="vocabulary.html#facet-task-io-device-keyboard">keyboard</a>, <a href="vocabulary.html#facet-task-io-device-computer-screen">computer screen</a>
  - Trial structure: <a href="vocabulary.html#facet-trial-structure-self-paced-trials">self paced trials</a>
  - Population: <a href="vocabulary.html#facet-population-young-adults">young adults</a>
- **Settings:** <a href="vocabulary.html#setting-block-duration">block duration</a>
- **Material:** Letter strings (such as MXRVXT) generated by a finite-state grammar, and at test new strings that do or do not follow it.

## Inclusion test

An experiment is an instance of this task when its procedure matches, it manipulates at
least one of the listed variables, and it records at least one of the listed measures.

```{list-table}
:widths: 15 85
:header-rows: 0

* - **Procedure**
  - 1. Participants study letter strings generated by a finite-state grammar during a training phase, then classify novel strings as grammatical or not.
    2. Optional: The test strings use a different letter set from training arranged by the same grammar, so only abstract rule knowledge can carry over.
* - **Manipulations**
  - - Grammar complexity
    - Training duration
    - Surface features (same vs. changed letter set at test)
    - Chunk strength
    - Presentation format (sequential, element by element vs. whole strings)
* - **Measurements**
  - - Endorsement rate (proportion judged grammatical)
    - d-prime separating grammatical from ungrammatical
    - RT
```

## Cognitive processes

This task is designed to engage the following processes:

- [Implicit memory](../processes/implicit_and_statistical_learning.md#hed-implicit-memory)
- [Procedural memory](../processes/implicit_and_statistical_learning.md#hed-procedural-memory)
- [Pattern recognition](../processes/face_and_object_perception.md#hed-pattern-recognition)
- [Categorization](../processes/reasoning_and_problem_solving.md#hed-categorization)
